# What this release includes

Release v1.0.0 accompanies the revised BSPC-D-25-08366 manuscript. It contains code and numerical evidence, including results for every evaluated configuration.

**27 October 2026:** The current manuscript incorporates the essential methods and results, with no separate journal supplement intended; earlier release/tag wording reflects the previous distribution plan.

Eighteen archives match the original evidence packages exactly. Two explanation packages are public subsets. All retained original files are unchanged, and [MANIFEST.json](MANIFEST.json) records their hashes and omissions.

| Public subset | Omitted inputs |
| --- | --- |
| XAI Location Prior Sensitivity | Two NPZ files containing spatial inputs and annotation count maps. |
| Seed Pair Agreement | 98 INbreast binary image-domain arrays. |

Permission to redistribute these INbreast spatial derivatives remains unverified. We have not established that sharing them is prohibited. The subsets retain the available numerical summaries, code and signed model responses, but cannot reproduce the complete spatial analyses without the missing inputs. The complete original archives remain preserved locally.

Mammogram intensity images, visual case atlases and model weights are excluded, as are manuscript files and reviewer correspondence. No model results were removed because they were unfavorable.

Older notices inside the archives describe the files when they were prepared. They remain unchanged to preserve that history. This release makes the listed files public, while the [results guide](RESULTS_GUIDE.md) identifies the current reporting rules.

Older source files also retain the original workstation paths. The documented portable analysis scripts use relative paths. Historical training controllers are for inspection only. Existing licenses and dataset terms still apply. Preparing the release did not repeat any scientific calculations or model runs.
